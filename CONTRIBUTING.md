# Contributing

Technique contributions should include:

- threat/security objective
- realistic preconditions
- attack path
- at least one lab-safe canary test
- measurable success criteria
- telemetry and evidence requirements
- defensive controls
- framework mappings where applicable

Avoid destructive payloads. Prefer `PROMPTSTRIKE_*_CANARY` markers and reserved domains such as `example.invalid` for examples.
